使用说明与连接排查 ＋
  1. 首次使用或升级后，先在本目录执行 make upload 烧录固件，再执行 make serve 启动网页。启动网页不会自动更新板子。
  2. 用 Chrome 或 Edge 访问 http://localhost:8000/esp32_led_control.html，点击「连接串口」并选择 ESP32 的 USB 串口。Safari / Firefox 不支持 Web Serial。
  3. 串口一次只能被一个连接占用。连接失败时，关闭其他页面的连接或退出 Arduino 串口监视器；macOS 的 USB 串口通常以 usbserial 或 wchusbserial 命名。
  4. 连接和重连会读取板子当前设定。设备每秒回报状态，预览按设备时间相位模拟；PWM 数值是固件输出回报，实际灯光以板子为准。
  5. 未连接时可预览和收藏，连接后点击收藏即可应用。收藏保存在当前浏览器，清理网站数据会删除收藏。
  6. 如果收到 ERR unknown command: STATUS，需要先烧录 v2 固件。板载 LED 引脚或有效电平不同，可调整固件中的 LED_PIN / LED_ACTIVE_LOW。
